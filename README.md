# Week 1 Pandas Data Analysis

This folder contains a Pandas solution for the Week 1 dataset cleaning and analysis task.

## Files

- `pandas_week1_analysis.py`: Python script that performs all required steps.
- `global_superstore_orders.csv`: CSV version of the Orders sheet used as the input dataset.
- `global_superstore_orders_cleaned.csv`: Dataset after duplicate and missing-value handling.
- `basic_info.txt`: Basic dataset information, data types, missing values, and first five rows.
- `category_revenue.csv`: Category-wise total revenue.
- `sorted_data_preview.csv`: First 100 rows after sorting by Category, Sales, and Profit.
- `correlation_matrix.csv`: Correlation matrix for numerical columns.

## Tasks Covered

1. Loaded a CSV file using Pandas and displayed basic information.
2. Handled missing values and duplicate rows using Pandas.
3. Grouped data by Category and calculated total revenue.
4. Sorted data by multiple columns using Python.
5. Created a correlation matrix for numerical columns.

## How to Run

```bash
python pandas_week1_analysis.py
```
